## Protección aplicada

La rama `Main` exige pull request, una aprobación, descarta aprobaciones obsoletas, exige rama actualizada, conversaciones resueltas, historial lineal y los checks `Quality` y `Database`. La regla también se aplica a administradores; force-push, eliminación y bypass ordinario permanecen deshabilitados.

`Dependency review` está configurado para pull requests y bloquea severidad alta o crítica. GitHub solo permite seleccionarlo como check requerido después de registrarlo al menos una vez; por eso se agregará a la regla tras el primer pull request.

El corte conectado agrega el job `Connected integration`. Se promoverá junto con `Dependency review` a check requerido cuando ambos queden registrados por el pull request de cierre.

Los avisos de runtime Node.js 20 observados en la primera ejecución motivaron la actualización a `actions/checkout@v7`, `actions/setup-node@v7` y `pnpm/action-setup@v6`, que se verifica mediante pull request antes de integrar.
